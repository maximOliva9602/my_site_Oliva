# Студія масажу Oliva — сайт

Темний luxury-лендінг для масажної студії **Oliva** (Київ, Солом'янський район,
вул. Борщагівська 145). Чистий HTML/CSS/JS, який роздається через невеликий
Node/Express-сервер — щоб згодом без переробок додати живий онлайн-чат і
деплоїти на **Railway**.

## Запуск локально

**Варіант 1 — просто відкрити файл.** Відкрийте `public/index.html` у браузері.
Працює без сервера (чат у режимі «месенджери»).

**Варіант 2 — через сервер (як на Railway):**
```bash
npm install
npm start
# http://localhost:3000
```

## Деплой на Railway

1. Залийте проєкт у GitHub-репозиторій.
2. Railway → **New Project → Deploy from GitHub repo** → оберіть репозиторій.
3. Railway сам визначить Node, виконає `npm install` і `npm start`.
4. Змінні середовища (Variables) — поки не потрібні; знадобляться, коли
   підключимо живий чат (див. `.env.example`: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_GROUP_ID`).
5. Прив'яжіть домен у Settings → Domains.

## 📋 Потрібно від замовника (заміна плейсхолдерів)

Шукайте у коді позначки `REPLACE_ME` та атрибути `data-replace="..."`.

| Що | Де замінити | Примітка |
|----|-------------|----------|
| **Фото галереї** | `public/index.html` → секція `#gallery` (`src` зображень) | реальні фото з Instagram @oliva_massage_studio |
| **Фото майстрів** | секція `#team` (зараз ініціали-плейсхолдери) | + підтвердити імена/ролі майстрів |
| **Hero-відео** | `assets/video/hero.mp4` + розкоментувати `<video>` у `#hero` | ≤8–10 МБ, 1080p, без звуку (muted) |
| **Відео/фото фітобочки** | `assets/video/phyto.mp4` або `img` у `#phyto` | аналогічно |
| **YouTube** | `data-replace="youtube"` (топ-бар, контакти) | вставити реальний URL каналу |
| **Telegram** | `data-replace="telegram"` (топ-бар, чат, контакти) | username/посилання бота/каналу |
| **Threads** | `data-replace="threads"` (топ-бар) | реальний URL |
| **Facebook** | `data-replace="facebook"` (топ-бар) | реальний URL сторінки |
| **Ціни/послуги** | секція `#services` + `assets/js/i18n.js` | звірити з актуальним прайсом |

> Логотип уже встановлено: `public/assets/img/logo.png`. Замінюється тим самим іменем файлу.

## Hero-відео: чи витримає сайт?
Так. Широкоформатне відео працює без проблем, якщо це **стиснений `.mp4` (H.264)
до ~8–10 МБ, 1080p, без звуку**, з `muted autoplay loop playsinline` і фото-постером
на час завантаження. Великі (50+ МБ) файли сповільнять перше відкриття — у такому
разі краще завантажити на YouTube/Vimeo та вбудувати. Розмітка під обидва варіанти
вже підготовлена в `#hero` (і в `#phyto`).
